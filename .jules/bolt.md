## 2024-05-24 - Pandas Memory Allocation Overhead
**Learning:** In pandas, filtering DataFrames within a loop sequentially creates new DataFrame allocations, which takes O(N) memory allocation overhead for each iteration. This is a significant bottleneck. Evaluating boolean masks cumulatively and applying them once at the end significantly speeds things up while changing the mathematical underlying behaviour. To optimize and keep progressive filtering behaviour, evaluate boolean masks cumulatively, calculate quantiles on `df.loc[mask, col]`, and then update the mask again before using it to filter at the end.
**Action:** Evaluate boolean masks cumulatively rather than sequentially modifying DataFrames within loops to avoid O(N) memory allocation overhead, using `df.loc[mask, col]` where intermediate data state calculations are required.
