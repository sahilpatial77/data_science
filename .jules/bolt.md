## 2024-09-05 - Optimizing Pandas String Operations with Map
**Learning:** Sequential `.str` accessors in Pandas (like `.str.strip().str.lower()`) on columns with repeating values are significantly slower than computing transformations on unique values in pure Python and applying them via `.map()`. Additionally, iterating over `.value_counts().items()` is much faster than computing aggregate conditions (like `.str.startswith().sum()`) across the entire column.
**Action:** When performing string transformations or aggregate checks on large text columns in Pandas, compute the unique values, build a mapping dictionary using pure Python logic, and apply it with `.map()`. Ensure to check `isinstance(val, str)` when dealing with potential `pd.NA` or `NaN` values, and append `.astype('string')` to the mapped result to prevent downcasting or type loss if missing values are introduced.
