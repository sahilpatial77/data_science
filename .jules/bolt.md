## 2024-09-12 - Optimize pandas string columns using .map() on unique values
**Learning:** When cleaning large pandas string columns with repeating values, computing expensive transformations (like `.str.strip()` and `.str.lower()`) on `.unique()` values using a Python dictionary and applying them via `.map()` is significantly faster than using sequential `.str` accessor methods over the entire column.
**Action:** When refactoring or profiling pandas string processing loops (especially for categorical-like text columns), check if mapping unique values provides a major performance boost over chained `.str` methods. Ensure to append `.astype('string')` to the mapped result to prevent the column from losing its explicit string dtype, especially if the mapping introduces `pd.NA`.
