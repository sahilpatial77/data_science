## 2024-05-24 - Sequential DataFrame Filtering Bottleneck
**Learning:** In pandas, sequentially modifying a DataFrame within a loop (e.g., `df = df[condition]`) for operations like outlier removal creates O(N) memory allocations per iteration, leading to significant performance degradation. Simply switching to a cumulative boolean mask without updating the subset changes the mathematical behavior (quantiles change as rows are dropped).
**Action:** To optimize performance while preserving progressive filtering behavior, evaluate boolean masks cumulatively and compute quantiles on the progressively masked data (e.g., `df.loc[mask, col]`).
