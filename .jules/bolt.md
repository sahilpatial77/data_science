## 2024-05-24 - Pandas Outlier DataFrame Reallocation
**Learning:** Sequential full-dataframe filtering inside a `for` loop `df = df[condition]` inside pandas causes massive O(N) memory allocations, memory fragmentation, and copying overhead, which scales poorly with large datasets. Using a `pd.Series` boolean mask inside the loop and progressively AND-ing the conditions, then filtering the dataframe exactly once at the end with `df = df[mask]`, drastically improves speed and memory utilization. When doing this, quantiles must be evaluated against the subset of valid data using `.loc[mask, col]` instead of the raw data.
**Action:** When filtering rows across multiple columns (e.g. outlier removal loop), use a cumulative boolean mask applied once at the end rather than serially re-allocating the DataFrame on every iteration.
