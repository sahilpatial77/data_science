## 2024-03-12 - Sequential Pandas Filtering Overhead
**Learning:** When repeatedly filtering and reallocating a DataFrame inside a loop (e.g., iteratively removing outliers across multiple columns with df = df[...]), Pandas incurs significant memory and performance overhead due to repeated object allocations. Furthermore, when computing subsequent statistics (like quantiles) inside the loop, they must be calculated only on the remaining valid rows to maintain logical correctness and mathematical bounds.
**Action:** Replace iterative DataFrame filtering loops with a sequential boolean mask (e.g., mask &= ...) applied outside the loop. To maintain logical parity, ensure dependent statistics for subsequent iterations are calculated only on the valid rows (e.g., df.loc[mask, col]).
