## 2024-09-05 - Optimizing pandas string operations
**Learning:** When standardizing large string columns in pandas with `.str` accessors, evaluating operations (like `startswith` and `endswith` for counts) and sequentially mapping multiple string transformations over the entire Series is remarkably inefficient. Repeating identical operations across millions of rows causes unnecessary redundant computation.
**Action:** Replace `.str` accessor chains with a process that extracts unique values (`df[col].unique()`), computes the transformations using pure Python dictionaries (`mapping`), and applies the final result uniformly with `.map().astype('string')`. Similarly, aggregate conditional counts using `.value_counts()` and calculate totals by iterating over the unique frequencies.
