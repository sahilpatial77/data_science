## 2024-05-17 - Pandas Iterative Filtering vs Boolean Masking\n**Learning:** Sequential DataFrame filtering inside loops (`df = df[...]`) forces Pandas to allocate new memory and copy the entire DataFrame each time, causing O(N) memory allocations and major performance bottlenecks.\n**Action:** Use a cumulative boolean mask (`mask = pd.Series(True, index=df.index)`) evaluated progressively (`df.loc[mask, col]`) and apply the mask only once at the end (`df = df[mask]`).
