## 2024-05-18 - Fast Datetime Parsing in Pandas
**Learning:** Optimizing `pd.to_datetime` by explicitly providing a `format` string significantly improves parsing speed, especially for large datasets. However, hardcoding a format with `errors='coerce'` in generic loops is dangerous, as format mismatches will silently convert valid dates to `NaT` instead of raising an error. Wrapping `pd.to_datetime(..., errors='coerce')` in a `try...except ValueError` block will not catch mismatches, as `coerce` suppresses `ValueError`s.
**Action:** To safely optimize, always test the format string against the first valid non-null value (e.g., using `.first_valid_index()`) with `errors='raise'`. If successful, apply the strict format with `errors='coerce'`; otherwise, fallback to standard inference.
